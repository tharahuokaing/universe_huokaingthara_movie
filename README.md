## 🎯 About the Platform / អំពីវេទិកា

**UNIVERSE HUOKAING THARA Movie Platform** is a modern cinematic media portal designed to showcase feature films, drama series, and high-definition video content. Built with a responsive cyberpunk-inspired dark theme, it integrates social media feed layouts with interactive video controls.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **📱 Facebook-Style Feed Cards:** Styled post cards featuring verified badges, view counters (15M+ views), publication timestamps, and interactive stats bars.
* **▶️ Click-to-Autoplay Integration:** Custom interactive video overlays with pulsing play triggers that instantly start iframe playback upon user interaction.
* **🌐 Dual Language Support:** Complete bilingual UI presentation in **Khmer (ខ្មែរ)** and **English**.
* **⚡ High-Performance Responsive UI:** Lightweight, modular HTML5/CSS3 and JavaScript architecture optimized for all devices.
* **🛡️ Security & Performance:** Clean modular file separation (`index.html`, `style.css`, `script.js`) ensuring lightning-fast load times.

## 🛠️ Tech Stack & Architecture / បច្ចេកវិទ្យាប្រើប្រាស់

- **Frontend:** HTML5, CSS3 (Flexbox & CSS Grid), JavaScript (ES6+)
- **Typography:** Google Fonts (`Kantumruy Pro`, `Poppins`)
- **Icons:** FontAwesome v6.4.0
- **Media Delivery:** Embedded YouTube Player API with custom JS triggers
